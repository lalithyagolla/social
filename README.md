# MERN Stack Social App

This is a full-stack MERN application built with MongoDB, Express.js, React.js, and Node.js. The app allows admin users to manage social content.

created a beautifully designed social media platform that allows users

Core Features:

JWT-based authentication with role management (User/Admin)
Credit points system for user engagement and rewards
Multi-platform feed aggregator (Twitter and Reddit integration)
Responsive dashboard with activity tracking and content management
Interactive content features (save, share, report)
Admin dashboard for user and content management
Dark/light mode theming system
Design Elements:

Modern color system with primary indigo (#4f46e5), accent teal (#0d9488), and supporting colors including success (#10b981), warning (#f59e0b), and error (#ef4444)
Clean, minimalist UI with purposeful animations on interactions
Card-based content design with subtle shadows and rounded corners
Responsive layouts optimized for mobile, tablet, and desktop experiences
Custom navigation that adapts to different screen sizes
Skeleton loading states for improved perceived performance
Visual credit indicators that celebrate user achievements
I've created a comprehensive social media platform application that allows users to manage their profiles, earn credits through engagement, and interact with content from Twitter and Reddit. This application features a clean, modern design with fluid animations, robust user authentication, and a credit-based reward system.

The platform includes dedicated dashboards for both regular users and administrators, with the admin interface providing powerful tools for managing users and monitoring platform activity. The application is fully responsive and includes dark/light mode for enhanced user experience.

To test the application, you can sign up for a new account or use any email/password combination to log in. For admin access, simply use an email address that contains "admin".
